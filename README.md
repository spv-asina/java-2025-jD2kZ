# Java — Технологии программирования

Учебные материалы по дисциплине «Технологии программирования». СПбПУ, 2025.

Коллекция презентаций и материалов команды 36 (и других команд) по различным темам Java:

- Collections, Stream API, Generics
- Принципы проектирования (SOLID, Decorator, Adapter, Proxy, Bridge, Factory)
- JVM, JIT-оптимизации, кеширование
- Многопоточность, исключения, рефлексия
- JDBC, WebSocket, Maven, JNI, JavaFX
- Аннотации, JUnit, JMM
- Java в машинном обучении

## Структура

Каждая директория — презентация команды по определённой теме.
