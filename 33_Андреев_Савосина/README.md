# Команда 33: TestNG + BankAccount

**Тема:** Тестирование в Java с использованием TestNG.

**Участники:** Андреев, Савосина

## Содержание

- `BankAccount.java` — тестируемый класс (банковский счёт с операциями пополнения/снятия)
- `BankAccountTest.java` — TestNG-тесты
- `TestNG.pptx` — презентация
- `pom.xml` — Maven-конфигурация с зависимостью TestNG
- `index.html` — отчёт о тестировании

## Запуск тестов

```bash
mvn test
```
